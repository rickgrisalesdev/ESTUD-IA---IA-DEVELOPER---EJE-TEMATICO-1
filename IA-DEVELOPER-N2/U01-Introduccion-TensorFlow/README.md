# 🎓 Unidad 1: Fundamentos de Programación y TensorFlow

## 🎯 **Objetivo de la Unidad**

Esta unidad establece los **fundamentos esenciales** de programación y TensorFlow, sirviendo como puente entre los conceptos básicos de la Unidad 0 y las aplicaciones avanzadas de la Unidad 2.

---

## 📋 **Contenido de la Unidad**

### **🧠 Laboratorio 1.1: Sistema de Reconocimiento de Emociones**
- **Tecnología**: Redes Neuronales Convolucionales (CNN)
- **Objetivo**: Clasificar emociones faciales en tiempo real
- **Habilidades**: Procesamiento de imágenes, OpenCV, TensorFlow básico

### **💻 Laboratorio 1.2: Fundamentos de Programación con Gemini**
- **Tecnología**: Python, Algoritmos básicos, Estructuras de datos
- **Objetivo**: Consolidar conceptos de programación fundamental
- **Habilidades**: Lógica de programación, patrones de diseño, buenas prácticas
